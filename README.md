```bash
git clone https://github.com/Prasad-Dalvi/campus-connect-ai.git
cd campus-connect-ai

python app.py
```

## 💡 Problem

80% of campus ambassador programs fail because:

* No visibility into **who is disengaging**
* No way to **predict drop-off early**
* Manual tracking across spreadsheets
* No **actionable insights**

👉 By the time managers react — it’s already too late.

## 🎯 Solution

**CampusConnect doesn’t just track — it actively fixes engagement.**

### 🔥 Key Innovation

## 🤖 AI Intervention Engine (Game Changer)

Unlike traditional dashboards:

* ✅ Detects at-risk ambassadors
* ✅ Explains **WHY** (transparent logic)
* ✅ Suggests corrective actions
* ✅ **Executes actions in one click**

👉 Example:

* Assign task automatically
* Send motivational message
* Activate bonus points

**All in under 2 seconds.**

## 🧠 Explainable AI (Trust Layer)

No black-box AI.

We show **exact reasoning**:

```
Inactive 4 days → +30

Total Risk Score: 80/100
```
